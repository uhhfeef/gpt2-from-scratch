# gpt2-from-scratch

GPT-2 written from scratch in PyTorch — no `transformers`, no pretrained weights.

This is the reference implementation behind
**[uhhfeef.com/building-mini-transformer](https://uhhfeef.com/building-mini-transformer/)**,
an interactive article that builds the model up line by line. Every snippet on
that page comes from this code. Site source:
[uhhfeef/uhhfeef.com](https://github.com/uhhfeef/uhhfeef.com).

| File | |
| --- | --- |
| `gpt2.py` | the implementation |
| `llm.ipynb` | the notebook it grew out of |
| `experiments/` | two scripts the article references |
